# 量仔 · Shor 大魔王档案

量仔的 Minimal Zine 风格个人主页，记录它与奶龙共同对抗 Shor 大魔王的传奇经历。

## 视觉设计

- 暖灰纸张、扫描颗粒与大面积留白
- 青蓝色作为主强调色，奶龙使用黄色档案标签
- 量仔原始精灵图以剪贴标本方式呈现
- 中文宋体、等宽小字与实验性杂志排版组合

## 页面内容

- 量仔角色档案
- 量仔生平与能力介绍
- 奶量同盟三幕传奇
- 可展开的战后时间记录
- 战后日常

## 本地运行

```bash
npm install
npm run dev
```

要求 Node.js 22.13 或更高版本。
