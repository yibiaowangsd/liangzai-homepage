# 旧首页视觉交互

首页默认展示量仔透明贴图，全屏背景粒子与下方交互粒子场保持开启。原“3D 星云”和“背景粒子”开关及展台封面按钮已移除。模型、WebGL 场景和模型分片不在首屏加载。

连续点击量仔三次后，才按需加载原有星云场景。场景准备好时，贴图像素爆散为粒子，露出星云；原有星云划过、长按聚拢、角色切换和双人融合交互继续可用。加载失败时显示场景已有的图片回退。减少动态效果的系统设置会跳过爆散动画。

进入其他页面再回首页保留当前会话的唤醒状态；刷新后从贴图重新开始。背景粒子使用单个 2D Canvas，暂停动效时停止连续刷新。

## 验证

1. 打开首页，确认显示量仔贴图和背景粒子，没有视觉开关；首屏 Network 没有角色模型分片与 `hero-scene` 请求。
2. 点击量仔一、二次时贴图仍在；第三次在场景准备好后爆散成星云。
3. 在星云中划过和长按，确认仍能唤醒角色、切换角色及融合。刷新页面应重新显示贴图。
4. 启用系统减少动态效果，确认第三次点击后跳过爆散动画；模拟 WebGL 加载失败，确认图片回退仍可见。
