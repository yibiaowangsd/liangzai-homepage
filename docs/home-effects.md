# 首页按需特效

首次服务端输出及 hydration 均为静态封面，不挂载 Canvas。客户端在一次轻量检测后选择默认值；不会先加载模型再判断。

- 逻辑线程数 ≤4、浏览器报告内存 ≤4 GB、节省流量、减少动态效果、已保存的暂停动效偏好，默认关闭特效。
- CPU 信息无法读取时采用轻量模式。内存 API 缺失不等同于 0 GB。
- 其余设备用一个 1×1 WebGL2 临时上下文读取显卡提示，随后释放。WebGL2 不可用、软件渲染、较老的 Intel HD/UHD 6xx 等集显采用轻量模式。
- 这些是保守的启发式规则，不是硬件跑分；浏览器隐私设置及当前负载可能影响判定。任何设备均可手动调整。

“3D 星云”控制角色模型、展台星云及相关 3D 场景；“背景粒子”控制全屏粒子与页面下方的交互粒子场。两者独立开启、关闭。仅在开启时触发对应 React.lazy 导入，关闭时卸载组件，沿用场景已有的请求中止、事件清理、帧调度停止、GPU 资源释放流程。轻量模式也阻止“关于我”链接悬停时的模型预加载及模型推页过渡。

本次客户端导航保留选择；刷新或重新访问重新判定，低性能设备不会因上次手动开启而自动加载。原“暂停动效”仍负责暂停动画，不等同于卸载特效。

## 验证

自动检查：`tests/visual-policy.test.mjs` 验证分级、缺失提示、手动覆盖、探测上下文释放；`tests/rendered-html.test.mjs` 验证首屏无 Canvas、无重型场景脚本预加载。配合现有渲染调度与资源释放测试。

浏览器验收步骤：

1. 在 4 线程或 4 GB 环境打开首页；确认静态封面及两个关闭的开关，Network 无模型分片、hero-scene、InteractiveGuardian、QuantumAtmosphere、QuantumSculpture 请求。
2. 悬停“关于我”、上下滚动，确认仍未请求模型；所有导航和文字内容可用。
3. 分别开启两个开关，确认仅加载相应功能；关闭后 Canvas 消失，加载中的模型请求被中止；重复快速开关验证无残留渲染。
4. 站内切换后回首页应保留选择；刷新低性能设备后应恢复轻量模式。
5. 在较高性能设备验证原模型切换、长按唤醒、双人合体与粒子互动；也可手动关闭特效。

当前执行环境未能安装可用的 Chromium，以上真实浏览器验收步骤尚未执行；不据此声称具体 FPS 或内存降幅。
