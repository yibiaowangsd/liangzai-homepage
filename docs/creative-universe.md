# 量仔 · 好奇心实验室

2026-10-02 全站重构。首页以巨大字标、实时数学纽结、可筛选作品画廊组织内容，随后依次连接作者宣言、角色星云展台、粒子雕塑与前沿新闻。没有强制横向滚动、滚轮劫持或必须等待的开场动画。

## 设计依据

研究的是表达方法，而非复制页面、标识或素材：

- [Miranda / Niccolò Miranda](https://www.niccolomiranda.com/)：刊物的排版节奏、大尺度字标与图文并置。
- [Obys](https://obys.agency/)：让作品自己成为入口，以及画廊与索引之间的浏览切换。
- [Bruno Simon](https://bruno-simon.com/)：个人主页中的互动应当产生实际反馈，邀请访客探索。
- [Lusion](https://lusion.co/)：通过视觉实验表达创作者，而不是让技术术语占据首屏。

纸白 `#f0eee6`、墨黑 `#242620`、电蓝 `#2447dd` 为全站主色。衬线中文用于想象、叙事与强调，无衬线用于导航和工程内容。保留经过压缩的现有角色与故事素材，不新增大型位图或 WebGL 依赖。

`app/studio/system.css` 是共享设计系统；`home.css` 管理首页；`FlowField.tsx` 绘制数学纽结；`ProjectAtlas.tsx` 管理工程/想象筛选及画廊/索引。旧五项首页索引组件与样式已经删除。

## 导航与阅读

主导航保留作品、实验室、新闻、关于我四个高频入口。全屏电蓝目录包含全部八个页面，桌面另有跟随选项的预览图。原生 dialog 限制焦点、支持 Escape、关闭后恢复触发按钮与滚动。独立实验室和接入记录页具有同样的全站目录。

「跃迁」或 Ctrl/Command + K 提供中文与算法关键词搜索；菜单打开时不能叠加快捷导航。首页新闻先显示轻量提示，点击才打开六条简报；关闭仍记录当前期次。失败的新闻请求不会覆盖页面或阻断首页。

## 动画预算与降级

首页数学纽结以 27 条曲线、每条 181 个采样点绘制。DPR 上限 1.5，画布宽度上限 1,500 像素；24 FPS 目标；低 CPU 设备静态绘制并按指针事件更新。离屏、后台和停用动效时不进行连续绘制。数学画布是装饰性体验，没有只有鼠标才能访问的导航。

角色 3D 场景只在展台三次点击后加载。WebGL 不可用时保留角色贴图和明确的重试入口。原有模型、凝聚、合体和降级引擎未更改。独立 Canvas 调度器在卸载时释放监听器与观察器。

## 观测站复现

`art-state.ts` 验证 `form/color/seed/density/energy`：未知值回退，数值取整并限幅。分享链接优先于浏览器保存的参数；链接复现初始构图参数，当前视角和动画时刻通过 PNG 留存。剪贴板受限时显示可手动复制的链接。

默认静止，主动播放以 30 FPS 为目标；点云最多 1,600 点，晶格使用固定邻接关系。画布 DPR 上限 1.5，像素上限 1,800 × 1,200；离屏/后台停止绘制。艺术随机数不得用于密码算法。

## 验收方法

执行 `npm test`（含构建、SSR、新闻、参数分享、模型资源、算法与真实 WASM 往返）、`npm run typecheck`、`npm run lint`、`git diff --check`。首页 SSR 继续验证真实目的地、角色贴图与延迟加载；档案断言同步为新的中文角色标识。

Chrome 浏览器验证桌面与窄屏布局、作品筛选、索引模式、全站目录、Esc 与焦点恢复、故事翻页和旁白。当前云浏览器禁用了 WebGL：实际验证的是星云不可用时的贴图回退，不能据此声称在真实 GPU 上完成了 3D 视觉验收。已有模型、几何和动画状态测试继续运行。

本地预览无法读取生产新闻 API，新闻数据及 HTTPS 路由需在 Cloudflare 部署后复核。`main` 继续触发现有 Cloudflare Git 集成，不使用独立 Sites 配置替换主站。实现中的帧率上限不等同于用户设备实测帧率。
