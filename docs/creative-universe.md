# 创意宇宙与灵感观测站

首页围绕「让想象穿越边界」组织探索入口：首屏邀请创作或选择路线，五项索引展示真实目的地，随后连接粒子雕塑、密码工程、故事与作者。继续沿用量仔贴图、三次点击唤醒星云、原有雕塑及故事素材。索引使用自然滚动，没有固定横向滚动区；用方向键、Home、End 也能切换并进入目的地。

## 创作与复现

`/observatory` 提供引力、共振和晶格三种数学光场，支持三种配色、密度、强度、拖动或键盘旋转、主动播放、复位、PNG 导出与参数分享。这是交互艺术，不是量子态模拟或密码随机源。

`art-state.ts` 集中验证 `form/color/seed/density/energy` 参数；未知值回退、数值取整并限制范围。分享链接优先于浏览器保存的参数。链接复现参数对应的初始构图；当前旋转角度和动画时刻不在链接中，保存 PNG 才能带走当前画面。非安全上下文或剪贴板拒绝时显示可选中的链接。

刷新保留参数，默认静止。参数变更创建新的确定性构图；暂停保留动画时间和视角；复位重新创建画布状态。艺术随机数不得用于实验室密钥或协议。

## 绘制预算

- Canvas 2D 绘制，不加载新的模型、WebGL 上下文或依赖。
- 点云最多 1,600 点；晶格使用固定邻接关系，避免两两连线。
- 背景预览静止；主工作台主动播放时使用现有帧调度器，以 30 FPS 为目标。
- 离屏、后台、顶部动效关闭或系统减少动态效果时停止连续绘制。仍允许参数和键盘触发单次重绘。
- DPR 上限 1.5，画布像素上限 1,800 × 1,200；卸载释放调度器、监听器与观察器。

这些是实现预算，不是对用户设备帧率或 Core Web Vitals 的实测承诺。

## 导航与弹窗

`destinations.ts` 为 React 导航、页脚和快捷搜索提供同一份路由。实验室是独立 HTML，使用普通链接避免 RSC 预取。独立实验室及接入记录页同步增加观测站入口，响应断点统一为 1,100px。

「跃迁」或 Ctrl/Command + K 打开原生模态对话框。搜索支持中文及算法关键词，方向键移动到真实链接，Enter 进入，Escape 关闭并恢复焦点及滚动。移动菜单打开时禁止叠加快捷导航；简报也不会自动覆盖已打开的对话框或移动菜单。

## 验证范围

`tests/observatory.test.mjs` 覆盖参数边界及复现、确定性点云、搜索路由和生产 SSR。现有前端工作流已加入这些检查。完整验证使用 `npm test`、`npm run typecheck`、`npm run lint` 与 `git diff --check`。

浏览器回归覆盖桌面首页、索引点击与键盘、三种光场、配色及滑块、暂停和复位、PNG 导出、分享链接恢复、快捷搜索与 Escape，以及 390/768/1,100px 的页面布局与手机导航。此次浏览器是 Chrome；并未因此声称在所有浏览器或真实手机 GPU 上均已实测。

本地 HTTP 环境的 Vinext RSC 缓存哈希依赖安全上下文，框架可能回退到整页导航；应在 Cloudflare 的 HTTPS 部署上核验实际站内切换。主域名继续使用现有 Cloudflare 部署，GitHub 合并与线上部署状态分别检查。
