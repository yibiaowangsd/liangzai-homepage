具体客户端/爬虫来源的 Zone HTTP Analytics 查询被现有 token 拒绝，缺少 `Zone Analytics Read` 权限。没有扩大权限或升级套餐。历史 Worker 调用日志原先未启用，也无法追溯恢复完整的历史请求明细。

## 实现和回归

- 为北京时间日期、板块及时间排序建立四个局部复合索引；递归定位日期时每轮查找上一有新闻的日期，并与日刊清单合并，保留历史、空板块和一天一页规则。
- 公开新闻 GET 使用最长 60 秒的 Cache API 缓存。只按有效参数和部署版本生成键；不同页码、日期、板块和搜索参数保持各自语义，未知日期也保留正确分页元数据。发布后最多等待 60 秒更新。
- 缓存未命中时，普通新闻每 IP 每分钟 120 次、搜索每 IP 每分钟 12 次，另有每机房共享每分钟 30 次的搜索未命中限额。原生限流不读写 D1；按机房尽力执行，不能视为账号每日读取量的严格全局上限。
- 管理、订阅令牌、POST、授权头/Cookie、404 和错误响应不进入公开缓存；跨域响应按当前调用者生成。限流返回 429，D1 配额故障返回 503，提供 Retry-After，不将失败伪装为空新闻。
- 邮件与机器人保持原有审核、邮箱确认、八板块选择、30 分钟任务周期、重试和幂等投递行为。

[最新 PR 完整 CI](https://github.com/yibiaowangsd/liangzai-homepage/actions/runs/39402661434)通过：268 项测试；Chromium、Firefox、WebKit 的新闻阅读、搜索、日期跳转及日历；八板块邮件/机器人订阅和补发回归；390 组路由/视口/引擎布局组合。构建、类型检查、lint（无错误）及 Wrangler 4.92.0 dry-run 通过。部署前核心回归再次通过。主题断言保留精确颜色要求，并等待渲染稳定。
