## 密码实验室

| 反馈 | 实现与验收点 |
| --- | --- |
| N / 征不明确 | 完整 `NIST 标准` / `国内征集` 分段入口。 |
| 运行状态点无说明 | 图例说明可运行/资料，提供仅显示可运行开关。 |
| 参数无选型依据 | NIST 参数选项展示安全等级、公钥、私钥、密文/签名字节数；KEM 另含共享密钥长度。当前材料大小在选择框下完整显示。 |
| SHAKE 单选项噪音 | 单项哈希方案为只读标签；SLH-DSA 的 SHA2/SHAKE 仍可选择。 |
| 清空含义和撤销 | `清空全部输入与结果`，保留算法选择，提供撤销；新编辑/操作后废弃旧快照。撤销材料仅保存在页内内存。 |
| 两套流程并列 | 密钥封装/签名/征集类别；引导/自由模式共用真实工作区状态，一次显示一种视图。 |
| 角色不一致 | Alice 生成密钥；KEM 中 Bob 封装、Alice 解封装；签名中 Alice 签名、Bob 验签。 |
| 状态词过多 | 主状态采用 `○ 未开始 / ◌ 进行中 / ✓ 完成 / ✕ 失败`，保留具体错误和操作说明。 |
| 前置条件未满足仍可点 | 有效材料长度校验后才启用发送、封装、解封装、签名和验签；按钮提示缺失条件。 |
| 操作离选择过远 | 桌面粘性算法栏和当前算法/进度条。 |
| 手机堆叠且下一步难找 | 引导模式为双角色说明和公开信道时间线；下一步固定于底部，回顶按钮避开操作条。算法库展开后保留可见滚动列表，不被新增控件挤压。 |
| 重复导入、复制文字 | 字段右上图标、提示和 aria-label；原生文件控件可用键盘。 |
| 复制无反馈 | 成功图标显示对勾约 1.5 秒，状态区播报；失败有错误反馈。 |
| 私钥公开展示 | 默认遮罩，主动显示；复制私钥提示不要分享并清理剪贴板。 |
| 格式与指纹不清 | 自动识别 HEX / Base64，显示完整材料的 SHA-256 截断指纹。 |
| 长 HEX 难读 | 输出按 4 字节分组，等宽显示，长字段可展开/折叠；复制材料仍可重新导入。 |
| 导入不便、长度报错含糊 | 支持拖拽和文件选择；粘贴与导入错误包含期望和当前字节数；错误就近展示。 |
| 切换算法隐式丢数据 | 已有材料时，算法、参数、类别切换均先确认；取消保留选项和输入。 |
| 结果仅三行小字 | 醒目结论条，成功/失败图标与颜色；并排共享密钥，差异字节带底色和下划线。 |
| 缺篡改演示 | 密文第一个字节最低位翻转后真实重新解封装；消息末字节最低位翻转后真实重新验签。 |
| 耗时混在一行 | 密钥生成、封装/签名、解封装/验签三段计时条和精确毫秒数。 |
| “运行”不明确 | 操作使用生成密钥对、封装共享密钥、解封装并比较、验证签名、计算摘要等明确名称。 |
| 真实密钥警告埋藏 | 输入工作区与每个导入材料旁常驻提示。 |
| 加载无失败或超时 | 模块就绪 15 秒、目录/报告 10 秒、运行请求 45 秒上限；骨架占位、错误说明、重试；候选哈希/密钥交换保留其独立超时与重试。 |
| 外链及 audit.html | 实验室资料和报告外链显示 ↗；应用内入口统一 `/pqc-practice/audit`，保留旧 HTML 兼容路径，查询参数不丢失。 |

## 回归入口

- `npm run typecheck`、`npm run lint`、`npm test`、`git diff --check`。
- `npm run test:usability`：真实加密流程、篡改、遮罩、撤销、取消参数切换、错误长度、拖拽、重试、导航一致性、主题、新闻、搜索、联系、序幕。
- `npm run test:layout`：Chromium、Firefox、WebKit 的 12 路由与 320～3840px 视口矩阵及交互。
- `npm run test:engineering-browser`：既有工程页面与真实混合 KEM。
- 浏览器截图在忽略目录 `outputs/usability/` 与 `outputs/responsive/`。未接入算法的测试跳过代表不支持，不代表验证通过。
