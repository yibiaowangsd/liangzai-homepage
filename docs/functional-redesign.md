# 功能导向的主页与统一实验室

2026-10-02，本轮遵循用户反馈：移除首页粒子与灵感观测站的反复推荐，优先实际功能；电影入场；独立模型鉴赏；统一实验室；减少装饰箭头；无图新闻使用关键词配图。不按设备性能分档。

## 信息架构

首页为电影式主视觉、密码实验室与图鉴、每日新闻、模型鉴赏与故事。`/observatory` 保留原地址兼容既有分享，不再进入首页、全站目录、搜索或页脚。`/models` 独立加载角色资源与 Three.js；主页不再导入旧星云模型或粒子组件。

`CinemaEntrance` 使用原生 dialog、4.8 秒开幕镜头、遮幅、标题进出和进度线。同一会话首次进入自动播放；支持跳过、Escape 和重看。关闭恢复滚动与焦点，卸载取消计时。只尊重明确的减少动画偏好，不检测 CPU、设备内存或省流状态。

模型页提供量仔、奶龙、双人、正侧背视角、自动旋转、缩放和重置。直接显示模型，不要求先完成星云长按操作。WebGL 不可用时明确显示状态，并可切换模型照片。资源加载被取消或部分失败时释放已完成模型，卸载释放材质、纹理、环境与渲染器。

## 统一视觉

实验室的核心工作区、算法侧栏、KEM/签名/密钥交换/哈希、报告与接入记录均使用纸白、墨黑、电蓝。旧样式中的直接颜色改为语义变量；`studio.css` 统一控件与状态，绿色/红色保留明确的成功/失败意义。按钮使用文字说明和状态变化，不把装饰性箭头当作通用导航标识。实际传输连线仍表达数据流向。

## 新闻图片

`app/news/keyword-cover.ts` 根据标题和标签确定配图，规则先匹配具体主题（FPGA、TLS、ML-KEM、Falcon、哈希、数字签名、AI、安全、标准、Web），再使用类别后备。保留有效原图与 contain 显示；缺失、旧通用 SVG 占位图或图片加载失败时使用本地关键词插画。正文、列表和首页简报共用 `StoryImage`。插画明确带主题关键词，不伪装为事件现场照片。

## 新图来源

使用内置 image_gen，未使用 CLI/API fallback。项目使用 WebP：

- `public/assets/cinematic/vault-entrance-v2.webp`：电影建筑主视觉，钛金属与陶瓷的环形密码之门，蓝色内室与银色晶体，左侧暗部留给标题，无文字、无粒子。
- `public/news-covers/compute-v2.webp`：暖白陶瓷电路板上的银色处理器，蓝色玻璃芯片，精密产品摄影，无文字与标志。
- `public/news-covers/connection-v2.webp`：银色网络模块由蓝色玻璃导管连接，象征加密协议与网络连接，统一暖白与电蓝配色，无文字与粒子。

生成提示词的完整英文原文保存在 `docs/image-prompts-20261002.json`。现有密码算法配图继续用于对应关键词。
