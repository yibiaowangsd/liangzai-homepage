# 深度研究发布约定

本目录独立于 news/inbox，不触发新闻入库、订阅或邮件。研究页为 /research，正文为 /research/<slug>。

每日选择一个具体问题，先核验原始资料，再新增一个符合 app/research/types.ts 的 JSON。将文件显式导入 app/research/entries.ts；列表按研究日期倒序。不要为凑数发布浅摘要。

每篇必须包含：问题、结论、证据边界、实际完成的研究过程、深入分析、比较基线、安全假设、局限与未解问题、可验证计划、原始来源及版本、修订记录。正文的 [n] 与 sources 的 id 对应。date 是研究日期，不是来源发布日期。

明确区分标准/草案/论文/预印本，作者声称/分析推断/实测证据，已完成/待执行。不得伪造测试、截图、性能图表、部署状态或声称新颖性/可专利性。后续实测应记录环境版本、方法、失败结果和证据位置。只公开可分享的研究方法和结果，不包含私人聊天、凭据、秘密或内部记录。

修改后运行 npm run typecheck、npm run lint、npm test，并在浏览器检查桌面和窄视口的目录、长表格、来源链接。PR 检查通过后按用户的仓库规则合并；核验线上正文而非仅报告 merge 成功。
