# TLS 1.3 票据切换实验 / 2026-11-28

在 Debian 13 x86-64、OpenSSL 3.5.9、Python 3、Bash 下，在本目录执行 `bash run.sh`。脚本只在 127.0.0.1 新建临时进程，生成一次性自签证书以及临时票据，不接触公网或真实凭据。它检查客户端和服务端握手扩展、证书签名消息、校验及 HTTP 响应，只保存汇总；退出时删除临时材料。建议复制目录后执行，避免覆盖随文发布的 results.txt。

前四次连接共用服务端进程；再启动只允许 X25519MLKEM768 的新进程，不导入旧进程票据保护状态，重试旧票据，并用新连接签发的票据复测。两阶段使用同一证书和套件。目标是观察票据、每次密钥交换、新鲜身份认证这三层，不测量时延。没有启用 0-RTT 或实现按票据签发批次选择性拒绝。
