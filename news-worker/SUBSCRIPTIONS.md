# 日报订阅

公开申请入口：`https://wangyibiao.com/news/subscribe`。
管理员审核入口：`https://wangyibiao.com/news/subscriptions/review`。

## 使用流程

1. 申请人填写本人邮箱、用途并选择五个核心板块中的一项或多项，同意订阅说明。
2. 申请以 `pending` 保存到现有 D1。待审核期间不发送邮件。
3. 管理员进入审核后台，输入审核口令后查看申请，批准或填写理由拒绝。
4. 批准后发送一次邮箱确认邮件，确认链接有效期七天。收件人点击确认按钮后才启用日报。邮件链接的 GET 不会启用或退订，避免邮件安全扫描器误操作。
5. 每十五分钟检查北京时间当天的完整日报（五个板块各至少五条），将获批板块各五条摘要与站内阅读、原文来源链接汇总为一封邮件。每个订阅每天最多一封，没有完整日报则等待，不发送空日报。
6. 邮件包含管理和退订链接；支持 `List-Unsubscribe` 一键退订。调整板块暂停发送并重新审核，保留已确认邮箱。待发送的旧板块邮件会取消，当天不补发第二封。已经交给邮件服务的邮件无法召回。

## 上线与邮件配置

已有 `Deploy news API Worker` 工作流会先对 **liangzai-news-prod** 应用 `news-worker/migrations`，再部署 **liangzai-news-api** 和 Cron。迁移仅新增订阅表，不修改新闻表。保留现有 Worker 环境变量。

在 Cloudflare 的 **liangzai-news-api → Settings → Variables and Secrets** 设置：

- `RESEND_API_KEY`：Resend 的邮件发送 API Key，作为 Secret 保存。
- `NEWSLETTER_FROM`：Resend 已验证发件域名上的地址，例如 `量仔日报 <daily@已验证域名>`；不能使用未验证的占位地址。
- `NEWSLETTER_ADMIN_TOKEN`：建议单独生成强随机审核口令，作为 Secret 保存。未设置时使用已有新闻发布 `ADMIN_TOKEN`。
- `NEWSLETTER_TOKEN_SECRET`：建议单独生成强随机签名密钥，作为 Secret 保存。未设置时使用已有 `ADMIN_TOKEN`，签名有独立用途前缀。更换密钥会使已有确认、管理与退订链接失效，应谨慎操作。

邮件未配置时申请仍可提交、查看和拒绝；批准操作被阻止，定时任务不会发送，审核页明确提示配置缺失。配置完成后批准申请即可运行。Resend 需开通可向真实收件人发送的权限，并为日报邮件配置相应的发件域名 DNS（SPF/DKIM/DMARC）和发送额度。

后台「发送当日日报」与自动任务采用相同审核、邮箱确认与去重规则，不绕过限制。邮件发送失败的获批申请仍需确认邮箱，后台可重发确认邮件。发送任务每轮最多 20 封，后续由定时任务继续；关注日志中的发送数量及失败数量。

## 数据与重试

D1 保存邮箱、选择的板块、称呼、申请理由、同意版本、审核记录和发送状态。管理口令仅保存在审核页内存中，不写入浏览器存储。接口不提供公开邮箱查询，重复申请不会覆盖待审核或已批准记录。

确认/管理/退订链接使用 HMAC 签名和不同操作用途；重新申请会更换令牌版本。公开申请有 8 KiB 请求限制、每 IP 每小时五次限制（仅保存带密钥哈希，不保存原始 IP）与隐藏反机器人字段。

日报采用 D1 唯一约束、原子发送租约和 Resend 幂等键。重试固定邮件正文，最多五次，并在首次尝试后二十三小时停止，避免超出 Resend 二十四小时的去重窗口。未送达记录可由管理员检查 D1 `newsletter_deliveries`，不要随意重置状态或幂等键。生产日志不记录邮箱、申请理由、口令、邮件正文和签名链接；关闭自动请求日志及追踪，防止记录令牌查询参数。

已退订的申请保留为停止发送的记录；如需删除个人信息，由管理员在 D1 删除该订阅的 `newsletter_deliveries` 和 `newsletter_subscribers`，无自动删除承诺。

## 验证

`node --test tests/news-subscriptions.test.mjs` 在真实 SQLite 上验证审核门槛、邮箱确认、板块筛选、去重、并发租约、固定重试、过期链接、退订、拒绝与板块重新审核。测试仅模拟邮件供应商，不发送真实邮件。
